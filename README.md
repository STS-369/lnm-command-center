# LNM Command Center

Unified CRM, Lead Generation, Sales Pipeline, and AI Agent Dashboard for SOETech.

## Features
- **Lead Management** — Track leads from discovery to close
- **AI Research** — 11-section deep research with confidence scoring
- **Sales Pipeline** — Lead → Research → Email → Proposal → Deal → Invoice
- **Multi-Agent System** — Sophia, Nyx, Luna, Alice, Zach
- **Real-Time Dashboard** — Live updates via Socket.io
- **Email Management** — Draft, approve, send workflow
- **Task Management** — Dispatch board and AI task queue

## Tech Stack
- **Frontend:** Next.js + React
- **Backend:** Next.js API Routes
- **Database:** PostgreSQL
- **Real-Time:** Socket.io
- **AI:** Abacus.AI (RouteLLM + Deployment)
- **Auth:** Google OAuth
- **Deploy:** Hostinger VPS + Nginx + SSL

## Development
```bash
npm install
npm run dev
```
